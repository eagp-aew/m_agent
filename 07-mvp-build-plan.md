# 07 — MVP Build Plan

## Goal

Complete one small task with:

```text
one work package
  → one scoped implementer
  → one verifier
  → one memory update
  → one reviewable diff
```

## Do first

- Verify scaffold.
- Fill project-specific memory.
- Identify one small work package.
- Run in a Worktree thread.

## Do not do yet

- recursive subagents;
- automatic merging;
- broad automations;
- huge role systems;
- multiple write agents;
- dependency upgrades.

## Success criteria

- Root thread stayed clean.
- Work package was clear.
- Implementer respected scope.
- Verifier produced evidence.
- Memory was updated.
- Diff was small.
