# 07 — MVP Build Plan

## Goal

Complete one small task with:

```text
one work package
  → one scoped implementer
  → one verifier
  → one memory update
  → one reviewable diff
```

## Do first

- Verify scaffold.
- Fill project-specific memory.
- Identify one small work package.
- Run in a Worktree thread.

## Do not do yet

- automatic merging;
- broad automations;
- huge role systems;
- dependency upgrades.

## After MVP policy additions

- Multiple write agents are allowed only through the guarded parallel implementer policy.
- Recursive subagents are allowed only as bounded depth-2, master-approved implementer child-agent requests.

## Success criteria

- Root thread stayed clean.
- Work package was clear.
- Implementer respected scope.
- Verifier produced evidence.
- Memory was updated.
- Diff was small.
