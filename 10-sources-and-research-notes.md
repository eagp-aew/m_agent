# 10 — Sources and Research Notes

This scaffold is based on patterns from:

- Codex `AGENTS.md` project instructions;
- Codex Skills;
- Codex custom agents/subagents;
- Codex app worktree-based isolated tasks;
- manager-worker/supervisor multi-agent patterns;
- verification-first software delivery workflows.

The operational design favors:

- durable memory over chat memory;
- bounded work packages over vague delegation;
- independent verification over self-reported success;
- worktrees for macro isolation;
- subagents for tactical isolation.
